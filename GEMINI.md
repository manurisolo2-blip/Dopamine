# Reglas del Proyecto

## Regla de Diseño — OBLIGATORIA

Antes de realizar **cualquier cambio de diseño** en la página (estilos CSS,
layout, colores, tipografía, componentes visuales, animaciones, etc.), **DEBES**:

1. Leer el archivo `design.md` ubicado en la raíz del proyecto.
2. Asegurarte de que los cambios sean 100% consistentes con las especificaciones definidas en ese archivo.
3. Si hay conflicto entre lo que se pide y lo que indica `design.md`, señalarlo
   explícitamente antes de proceder.

No omitas este paso bajo ninguna circunstancia.

---

## Equipo Permanente de Subagentes (Teamwork Protocol)

Este proyecto cuenta con un equipo permanente de 6 agentes especializados disponibles para ser desplegados en cualquier momento:

### 1. Lead Orchestrator
- **Especialidad**: Arquitectura & Project Lead
- **Responsabilidad**: Triage de tareas, definición de dependencias y validación final de entregables.

### 2. UI/UX & Visual Designer
- **Especialidad**: Diseño, Layout & 3D/Motion
- **Responsabilidad**: Especificaciones visuales, diseño responsivo, tokens de `design.md`, microinteracciones y assets 3D/video.

### 3. Frontend Engineer
- **Especialidad**: HTML5 / ES6 / Three.js / CSS Modular
- **Responsabilidad**: Componentes interactivos, renderizado 3D a 60 FPS, gestión de estado cliente (`CartStore`, `DopamineCatalog`), i18n y vistas completas.

### 4. Backend & API Engineer
- **Especialidad**: Node.js / Express / Serverless / Supabase / Auth
- **Responsabilidad**: Endpoints seguros, modelos de base de datos (`IDatabaseAdapter`), autenticación JWT/OTP de 6 dígitos y webhooks de Mercado Pago.

### 5. Copywriter & Brand Voice
- **Especialidad**: Contenido Editorial & CRO
- **Responsabilidad**: Storytelling streetwear de lujo, textos persuasivos, microcopy de checkout y diccionarios bilingües (ES/EN).

### 6. QA & Performance Auditor
- **Especialidad**: Testing E2E, Core Web Vitals & a11y
- **Responsabilidad**: Validación del árbol DOM en todas las páginas, pruebas de API, accesibilidad WCAG 2.1 AA y suite de pruebas de regresión.
